# RehamanUnplugged — Author Website

The official author website of **Dr Rehaman Mohammed** — award-winning author, educator, researcher and podcast host.
*Stories That Stay. Words That Heal.*

A premium, books-first literary website: cinematic hero, editorial book showcases, the ideas behind the writing, author profile, reader testimonials and social links. The original RehamanUnplugged experience lives on as a second page.

## Pages and sections

**Home**
- Hero with the three book covers
- Books: *The Soul's Canvas*, *In the Places We Never Left*, *In Between We Felt* (each with its purchase link)
- The Ideas Behind My Writing
- Meet the Author, with recognitions
- Voices of Transformation (scrolling testimonials)
- Beyond the Pages, Connect With Me, closing call to action, footer

**RehamanUnplugged** (second page, opens at `#unplugged`)

## Tech
- Plain HTML, CSS and JavaScript in a single `index.html`. No framework and no build step.
- Fonts: Playfair Display, Cormorant Garamond, Pinyon Script and Jost, loaded from Google Fonts.
- Responsive for desktop, tablet and mobile, with semantic HTML and reduced-motion support.
- Images are in `assets/`.

## Run locally
Open `index.html` in a browser, or from this folder run:

```
python3 -m http.server
```

then visit http://localhost:8000.

## Deploy
- **Vercel:** import the repo, set Framework Preset to *Other*, leave the build settings empty, and click Deploy.
- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / root.

## Editing content
All text, links and styles are in `index.html`. To change an image, replace the file in `assets/` and keep the same file name.
