# RehamanUnplugged — Author Website

Books-first author website for Dr Rehaman Mohammed. Static site: `index.html` + `assets/`. No build step.

- **Home:** hero, three books (The Soul's Canvas, In the Places We Never Left, In Between We Felt), writing, author, testimonials, social links.
- **Second page:** RehamanUnplugged (open with `#unplugged`).

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server`.

## Deploy (GitHub Pages)
Settings → Pages → Deploy from branch → `main` / root.

## Editing
Copy, links and styles live in `index.html`. Replace images in `assets/` keeping the same file names.
